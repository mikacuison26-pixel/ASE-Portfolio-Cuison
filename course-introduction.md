# Course Introduction

**Course:** CPELX230-330 – Computer Engineering

**Activity:** Exploring Agentic Software Engineering and Responsible AI

This activity introduces the concepts of Agentic Software Engineering and Responsible AI. It focuses on understanding how AI agents work, how they differ from traditional software applications, and how they can be used in modern software development.

It also discusses the importance of Agile methods, version control, teamwork, and responsible AI development. Through this activity, I aim to gain a better understanding of how intelligent systems can be developed and used to solve real-world problems while considering safety, privacy, and ethical responsibilities.
