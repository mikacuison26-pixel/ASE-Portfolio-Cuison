# Personal Learning Goals

Through this course activity, I aim to develop a better understanding of Agentic Software Engineering and how artificial intelligence can be applied in modern software development.

My learning goals are:

1. **Understand AI Agents** – Learn how AI agents work, make decisions, and perform tasks to achieve specific goals.

2. **Explore Agentic Software Engineering** – Understand how AI agents are used in developing smarter and more adaptable software systems.

3. **Learn Agile Development** – Understand how Agile methods help developers plan, organize, and improve software projects through teamwork and continuous feedback.

4. **Develop Version Control Skills** – Gain experience using Git and GitHub to manage project files, track changes, and organize development work.

5. **Understand Responsible AI** – Learn the importance of protecting user privacy, ensuring safety, avoiding bias, and maintaining human oversight when developing AI-powered applications.

## Expected Outcome

By completing this activity, I hope to improve my knowledge of software engineering practices and understand how AI can be used responsibly to create useful and reliable solutions to real-world problems.
